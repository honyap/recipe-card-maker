# A4シートテンプレート構想

直売所などが配布する「レシピカード」（A4・1枚に複数レシピ）を、テンプレート＋JSONデータで生成できるようにする構想。

参考サンプル: 風土記の丘農産物直売所「#風土記農家レシピ」No.025（2022年6月・実山椒）。

## テンプレートのスロット分解

| 層               | 内容                                                                      | 更新頻度             |
| ---------------- | ------------------------------------------------------------------------- | -------------------- |
| 固定枠           | シリーズ名ロゴ / 発行元フッター（名称・住所・電話・QR）                   | 一度設定して使い回し |
| 号ごと           | 発行年月 / テーマ食材 / レシピ番号                                        | 号単位               |
| レシピブロック×N | タイトル / 材料（人数前） / 作り方（番号付き） / 写真 / ※ひとことコメント | レシピ単位           |
| 任意コラム       | 吹き出し枠（共通の下ごしらえ等）                                          | 号 or レシピ単位     |

サンプルでは1枚に2レシピ＋両レシピ共通のコラム（実山椒の佃煮の作り方）が付く構成。

## JSONデータ構造

```json
{
  "issue": {
    "series": "#風土記農家レシピ",
    "publisher": {
      "name": "風土記の丘農産物直売所",
      "address": "山梨県甲府市下曽根町1070-3",
      "tel": "055-266-3858",
      "qr": "https://twitter.com/funocho"
    },
    "date": "2022-06",
    "theme": "実山椒",
    "number": 25,
    "columns": [
      {
        "id": "tsukudani",
        "title": "実山椒の佃煮",
        "body": "実山椒を枝から手で取り…"
      }
    ]
  },
  "recipes": [
    {
      "title": "実山椒のザクザク唐揚げ",
      "servings": 2,
      "accentColor": "#9b59b6",
      "ingredients": [
        { "name": "実山椒の佃煮", "amount": "大さじ1" },
        { "name": "鶏モモ肉", "amount": "1パック" }
      ],
      "steps": ["鶏モモ肉をひと口大に切る。", "…"],
      "photo": "karaage.jpg",
      "note": "しびれる辛さの実山椒…無限唐揚げです♪",
      "columnRefs": ["tsukudani"]
    }
  ]
}
```

設計判断:

- 3層構造（publisher=固定 / issue=号ごと / recipes[]=可変）に分ける
- コラムは issue 直下に定義し、各レシピから `columnRefs` で参照する（サンプルのように複数レシピが同じ下ごしらえを共有するケースに対応）

## 既存機能との関係

- 現行アプリは1レシピ=1カード。本構想は「複数レシピを1枚のA4シートに配置する」出力レイヤーの追加
- 印刷/PDFサイズ対応の作業（pageSizes / pdf / print、worktree `print-pdf-sizes` に未コミットで存在）がA4出力の土台になる
- 未対応の要素: 1枚複数レシピ / 補足コラム / 発行元・連番フッター
